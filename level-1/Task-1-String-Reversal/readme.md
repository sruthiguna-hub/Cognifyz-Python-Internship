# String Reversal

## Project Description

This Python program reverses a string entered by the user. It accepts a string as input and displays the reversed version using a Python function.

## Features

* Accepts user input.
* Reverses the given string.
* Displays the reversed string.
* Simple and beginner-friendly program.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter a string when prompted.
4. View the reversed string in the terminal.

## Example

### Input

```
hello
```

### Output

```
olleh
```
