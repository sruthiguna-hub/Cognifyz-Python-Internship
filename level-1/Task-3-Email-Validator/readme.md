# Email Validator

## Project Description

This Python program validates whether a user-entered email address is valid. It checks for the presence of the "@" symbol and a valid domain name before displaying the result.

## Features

* Accepts an email address from the user.
* Checks for the "@" symbol.
* Checks for a valid domain name.
* Displays whether the email address is valid or invalid.
* Beginner-friendly Python program.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter an email address.
4. View the validation result in the terminal.

## Example

### Input

```text
abc@gmail.com
```

### Output

```text
Valid Email Address
```
