# Calculator Program

## Project Description

This Python program performs basic arithmetic operations. The user enters two numbers and an operator (+, -, *, /, %) and the program calculates and displays the result.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Handles invalid operators.
* Prevents division and modulus by zero.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter the first number.
4. Enter an operator (`+`, `-`, `*`, `/`, `%`).
5. Enter the second number.
6. View the result in the terminal.

## Example

### Input

```text
20
+
10
```

### Output

```text
30.0
```
