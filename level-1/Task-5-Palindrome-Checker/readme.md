# Palindrome Checker

## Project Description

This Python program checks whether a given word is a palindrome. A palindrome is a word that reads the same forward and backward, such as "madam" or "racecar".

## Features

* Accepts user input.
* Checks whether the entered word is a palindrome.
* Displays the result.
* Simple and beginner-friendly Python program.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter a word.
4. View the result in the terminal.

## Example

### Input

```text
madam
```

### Output

```text
It is a Palindrome.
```
