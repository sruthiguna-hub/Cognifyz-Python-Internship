# File Manipulation - Word Counter

## Project Description

This Python program reads a text file, counts the occurrences of each word, and displays the results in alphabetical order.

## Features

* Reads data from a text file.
* Counts the frequency of each word.
* Ignores common punctuation.
* Displays the words in alphabetical order.
* Beginner-friendly Python project.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Create a file named `sample.txt` and add some text.
3. Run the `main.py` file.
4. View the word counts in the terminal.

## Example

### Input (`sample.txt`)

```text
Python is easy.
Python is powerful.
Python is fun.
```

### Output

```text
easy : 1
fun : 1
is : 3
powerful : 1
python : 3
```
