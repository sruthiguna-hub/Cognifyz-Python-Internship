# Password Strength Checker

## Project Description

This Python program checks the strength of a password entered by the user. It evaluates the password based on its length and whether it contains uppercase letters, lowercase letters, numbers, and special characters.

## Features

* Accepts password input.
* Checks password length.
* Detects uppercase letters.
* Detects lowercase letters.
* Detects digits.
* Detects special characters.
* Displays whether the password is Strong, Medium, or Weak.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter a password.
4. View the password strength in the terminal.

## Example

### Input

```text
Abc@1234
```

### Output

```text
Strong Password
```
