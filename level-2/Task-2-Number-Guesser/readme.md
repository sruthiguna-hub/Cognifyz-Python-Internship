# Number Guesser

## Project Description

This Python program creates a number guessing game. The user first selects the starting and ending numbers of the range. The program then generates a random number within that range, and the user continues guessing until the correct number is found.

## Features

* User-defined number range.
* Random number generation.
* Provides "Too High" and "Too Low" hints.
* Repeats until the correct guess is entered.
* Beginner-friendly Python project.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter the starting and ending numbers.
4. Guess the generated number.
5. Continue until you guess correctly.
