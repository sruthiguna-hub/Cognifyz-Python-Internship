# Guessing Game

## Project Description

This Python program generates a random number between 1 and 100. The user tries to guess the number, and the program provides hints whether the guess is too high or too low until the correct number is guessed.

## Features

* Generates a random number.
* Accepts user guesses.
* Gives "Too High" and "Too Low" hints.
* Continues until the correct guess is made.
* Beginner-friendly Python program.

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## How to Run

1. Open the project in VS Code.
2. Run the `main.py` file.
3. Enter a number between 1 and 100.
4. Continue guessing until you find the correct number.
